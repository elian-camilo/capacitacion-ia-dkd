# Capacitación de IA para DKD

Material de estudio de la capacitación en desarrollo con IA para el equipo
de DKD, dictada por Carlos René Angarita Sanguino y Elian Camilo Angarita
Sanguino.

Cada sesión tiene su carpeta con todo lo que se vio: diapositivas, apuntes,
demo y plantillas.

| Sesión | Fecha | Tema |
|---|---|---|
| [sesion-1](sesion-1/) | 2026-10-21 | Reglas y skills |
| [sesion-2](sesion-2/) | 2026-10-28 | Contexto: ventana, tokens, compactación y consumo |
| [sesion-3](sesion-3/) | 2026-11-04 | Desarrollo guiado por specs (SDD) |
| sesion-4 | 2026-11-11 | Subagentes |
| sesion-5 | 2026-11-18 | Harness completo y adopción |
